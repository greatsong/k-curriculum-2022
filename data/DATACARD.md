# 데이터 카드 (Data Card)

"무엇을 위해 만들었고 무엇에 쓰면 안 되는가"를 적습니다. 필드 정의는 [docs/SCHEMA.md](../docs/SCHEMA.md), 변경 이력은 [CHANGELOG.md](../CHANGELOG.md), 건수의 정본은 [manifest.json](./manifest.json)입니다.

## 개요

대한민국 교육부 고시 2022 개정 교육과정의 성취기준 6,444건 전부. 교육부 별책 PDF 원문 그대로(verbatim)이며 행마다 출처 별책을 적었습니다.

| 파일 | 항목 수 | 설명 |
|------|--------|------|
| `standards.json` | 6,444 | 정본 |
| `standards.csv` | 6,444 | 스프레드시트용 파생본 |
| `manifest.json` | — | 스키마 버전(3), 출처 커밋, 건수, 식별자 규약 |

## 의도된 용도

- 교육과정 검색·조회 도구, 수업 설계 도구, 평가 도구의 성취기준 사전
- 교과·학년군·영역 단위 교육과정 분석(분포, 문장 구조, 역량 표현)
- 성취기준을 노드로 쓰는 지식 그래프의 기준 노드 집합
- LLM·RAG 응용의 근거 문서 — 원문 verbatim이라 인용해도 됩니다

## 이렇게 쓰지 마세요

- **원문 대신 인용하지 마세요.** 공식 인용은 교육부 고시 원문(NCIC)으로 하고, 이 데이터는 기계 가독 사본입니다. `source_book`·`source_doc`이 대조할 문서를 가리킵니다.
- **`code`로 조인하지 마세요.** 같은 코드가 두 과목에 쓰인 11건이 있어 식별자는 `key`입니다.
- **`keywords`를 의미 분석에 쓰지 마세요.** 본문 앞 어절을 단순 분리한 값입니다.
- **빈 `explanation`을 결측으로 처리하지 마세요.** 원문에 해설이 없는 것입니다(29%).
- **산업수요 전문교과의 빈 `school_level`을 채우지 마세요.** 원문이 학교급을 명시하지 않습니다.

## 생성 방법

교육부 고시 별책 PDF 19종을 별책별 파서로 추출하고, 완결성·문장 verbatim·학교급·교과 귀속·영역·해설·고려사항·형식의 8개 게이트를 전부 통과한 것만 정본으로 삼았습니다(2026-09). 수식의 사설 영역(PUA) 글리프는 원문 대조로 유니코드 표준 기호로 복원했습니다. 학교급·학년군은 코드 접두 규칙으로 생성하고 게이트에서 검사합니다. 원천은 [curriculum-weaver](https://github.com/greatsong/curriculum-weaver)의 정본이며, 이 리포는 그것을 공개 스키마로 수출한 것입니다.

## 분포

학교급: 초등 611 · 중학 714 · 고등 3,126 · 산업수요 전문교과 1,993. 별책별 건수는 [README](../README.md#원문--source).

## 한계 (요약 — 전체는 [KNOWN_ISSUES.md](../KNOWN_ISSUES.md))

- 자동 게이트와 표본 검토로 확인했고, 사람이 원문을 눈으로 전수 대조하지는 않았습니다.
- 원문의 오탈자·표기 흔들림은 그대로 둡니다.
- 복잡한 수식은 한 줄 텍스트로 평탄화되어 원문 조판과 다를 수 있습니다.

## 무결성 검증

```bash
node scripts/validate.mjs
```

코드 형식, `key` 고유성, 필수 필드, 학년군 값, manifest 건수를 검사합니다. PR마다 GitHub Actions가 같은 검사와 CSV 일치 검사를 돌립니다.
