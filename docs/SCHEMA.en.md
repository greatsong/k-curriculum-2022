# Schema (v3)

`schema_version` in `data/manifest.json` must match this document. Schema changes bump the version and are recorded in the [CHANGELOG](../CHANGELOG.md). The same definitions are machine-readable in [datapackage.json](../datapackage.json). *[한국어](./SCHEMA.md)*

## Files

| File | Content | Order |
|---|---|---|
| `data/standards.json` | Array of standards (canonical) | `key` ascending |
| `data/standards.csv` | Same rows as CSV (UTF-8 with BOM; `keywords` joined by `;`) | same |
| `data/manifest.json` | Schema version, provenance commit, counts, identity convention | — |

Ordering is deterministic so releases can be `diff`ed. JSON is canonical; the CSV is generated by `scripts/build-csv.mjs`.

## Fields

| Field | Type | Meaning |
|---|---|---|
| `code` | string | Achievement-standard code as printed in the notice, brackets included. Five shapes occur: `[4과01-01]`, `[10공영1-01-01]` (three segments), `[9사(지리)01-03]` (parenthesised subject), `[12미적Ⅰ-02-03]` (Roman numeral), `[공관 01-01-01]` (vocational, with a space) |
| `key` | string | **Unique identifier.** Equals `code` except for 11 code collisions, where it is `"code\|subject"` (see below) |
| `subject_group` | string | Subject group (20) |
| `subject` | string | Subject (292). Some primary subjects carry the grade band in the name (`사회(4학년)`) |
| `school_level` | string | `초등학교` elementary, `중학교` middle, `고등학교` high. **Empty for industry-demand vocational subjects** |
| `grade_group` | string | Grade band: `초1-2` (grades 1–2), `초3-4`, `초5-6`, `중1-3` (middle), `고공통` (high, common), `고선택` (high, elective), `기타` (vocational) |
| `curriculum_category` | string | `공통` common · `일반선택` general elective · `진로선택` career elective · `융합선택` convergence elective · `선택` middle-school elective · `전문공통` / `전공일반` / `전공실무` vocational common / major-general / major-practice |
| `area` | string | Content-area heading from the source |
| `content` | string | The standard, verbatim from the notice. Single line, ends with a period |
| `keywords` | string[] | Naive tokens from the leading words of the text; search aid only |
| `explanation` | string | Official explanation where the source provides one (71% of rows). Explanations covering several codes are copied to each |
| `application_notes` | string | Area-level "notes for applying the standards", every bullet prefixed with `• ` |
| `source_book` | string | Appendix (별책) number this row was extracted from, e.g. `별책8` |
| `source_doc` | string | Source document title, e.g. `[별책8] 수학과 교육과정`; look it up on NCIC by this title |

### School level and grade band come from the code prefix

| Code prefix | `school_level` | `grade_group` |
|---|---|---|
| `[2…]` | 초등학교 | 초1-2 |
| `[4…]` | 초등학교 | 초3-4 |
| `[6…]` | 초등학교 | 초5-6 |
| `[9…]` | 중학교 | 중1-3 |
| `[10…]` | 고등학교 | 고공통 |
| `[12…]` | 고등학교 | 고선택 |
| Korean abbreviation (`[공관 …]`) | (empty) | 기타 |

Note that the digit `2` means grades 1–2, not grade 2. This convention is not stated as a field anywhere in the source documents ([docs/NOTES.md](./NOTES.md), Korean).

### Why `key` exists

The Ministry's code scheme collides across subjects: `[12심독01-01]`–`[12심독02-04]` (8 codes) are used by both *Advanced English Reading and Writing* and *Advanced German*; `[12스문01-01]`–`[12스문01-03]` (3 codes) by both *Sports Culture* and *Spanish-speaking Cultures*.

- For the 6,433 non-colliding rows, `key === code`.
- For each colliding pair, **one side** (Advanced English R&W, Sports Culture) keeps `key === code` and **the other** (Advanced German, Spanish-speaking Cultures) uses `"[12심독01-01]|심화 독일어"`.
- Always join, group, and reference by `key`. Looking up a bare colliding code silently resolves to one side.
- `source_code` / `target_code` in the [links repository](https://github.com/greatsong/k-curriculum-2022-links) are these `key` values.
