# 데이터 스키마 (schema v3)

`data/manifest.json`의 `schema_version`이 이 문서의 버전과 같아야 합니다. 스키마가 바뀌면 버전을 올리고 [CHANGELOG](../CHANGELOG.md)에 적습니다. 기계가 읽는 정의는 [datapackage.json](../datapackage.json)에 같은 내용이 있습니다. *[English](./SCHEMA.en.md)*

## 파일

| 파일 | 내용 | 정렬 |
|---|---|---|
| `data/standards.json` | 성취기준 배열 (정본) | `key` 오름차순 |
| `data/standards.csv` | 같은 내용의 CSV 파생본 (UTF-8 BOM, `keywords`는 `;` 구분) | 위와 같음 |
| `data/manifest.json` | 스키마 버전 · 출처 커밋 · 건수 · 식별자 규약 | — |

정렬이 고정돼 있어 두 릴리스를 `diff`로 비교할 수 있습니다. JSON이 정본이고 CSV는 `scripts/build-csv.mjs`로 만듭니다.

## 필드

| 필드 | 형 | 설명 |
|---|---|---|
| `code` | string | 교육부 고시의 성취기준 코드. 대괄호 포함, 원문 표기 그대로. 형식이 다섯 가지 — `[4과01-01]`, `[10공영1-01-01]`(3단), `[9사(지리)01-03]`(괄호), `[12미적Ⅰ-02-03]`(로마숫자), `[공관 01-01-01]`(전문교과, 공백) |
| `key` | string | **고유 식별자.** 기본은 `code`와 같고, 같은 code가 두 과목에 쓰인 11건만 `"code\|subject"` 형식 (아래 참고) |
| `subject_group` | string | 교과군 20종: 국어·수학·사회·과학·영어·도덕·체육·음악·미술·실과·기술·가정·정보·한문·제2외국어·교양·통합교과·과학계열전문·체육계열전문·예술계열전문·산업수요전문 |
| `subject` | string | 과목 292종. 초등은 학년군이 이름에 붙는 경우가 있음(`사회(4학년)`, `실과(초등 5~6학년)`) |
| `school_level` | string | `초등학교` `중학교` `고등학교`. **산업수요 전문교과는 빈 문자열** |
| `grade_group` | string | 학년군: `초1-2` `초3-4` `초5-6` `중1-3` `고공통` `고선택` `기타`(산업수요 전문교과) |
| `curriculum_category` | string | `공통` `일반선택` `진로선택` `융합선택` `선택`(중학 선택 교과) `전문공통` `전공일반` `전공실무` |
| `area` | string | 원문의 성취기준 소제목(영역). 별책23은 학습 영역명 |
| `content` | string | 성취기준 본문. 고시 원문 verbatim, 줄바꿈 없음, 문장 끝 마침표 |
| `keywords` | string[] | 본문 앞 어절을 단순 분리한 값. 검색 보조용이며 의미 분석에는 부적합 |
| `explanation` | string | 성취기준 해설. 원문에 해설이 있는 경우만(전체의 71%). 여러 코드를 묶은 해설은 각 코드에 복제 |
| `application_notes` | string | 영역 단위 "성취기준 적용 시 고려사항" 전체. 불릿마다 `• ` 접두 |
| `source_book` | string | 이 행이 실린 별책 번호 (`별책8`) |
| `source_doc` | string | 원문 문서 제목 (`[별책8] 수학과 교육과정`). NCIC에서 같은 제목으로 열람 |

### 학교급·학년군은 코드 접두에서 옵니다

| 코드 접두 | `school_level` | `grade_group` |
|---|---|---|
| `[2…]` | 초등학교 | 초1-2 |
| `[4…]` | 초등학교 | 초3-4 |
| `[6…]` | 초등학교 | 초5-6 |
| `[9…]` | 중학교 | 중1-3 |
| `[10…]` | 고등학교 | 고공통 |
| `[12…]` | 고등학교 | 고선택 |
| 한글 약어 (`[공관 …]`, `[성직 …]`) | (빈 문자열) | 기타 |

숫자 `2`가 "2학년"이 아니라 1~2학년군인 점에 주의하세요. 이 규칙은 교육부 문서 어디에도 필드로 명시돼 있지 않고 코드 관례에서만 읽힙니다([docs/NOTES.md](./NOTES.md)).

### `key`가 왜 필요한가

교육부 코드 체계가 과목 간에 겹칩니다. `[12심독01-01]`~`[12심독02-04]` 8건은 「심화 영어 독해와 작문」과 「심화 독일어」에, `[12스문01-01]`~`[12스문01-03]` 3건은 「스포츠 문화」와 「스페인어권 문화」에 같은 코드로 쓰였습니다.

- 겹치지 않는 6,433건은 `key === code`입니다.
- 겹치는 11건 중 **한쪽**(심화 영어 독해와 작문·스포츠 문화)은 `key === code`이고, **다른 쪽**(심화 독일어·스페인어권 문화)만 `"[12심독01-01]|심화 독일어"` 형식입니다.
- 조인·집계·참조는 항상 `key`로 하세요. 맨 코드로 조회하면 한쪽으로 조용히 풀립니다.
- [연결 리포](https://github.com/greatsong/k-curriculum-2022-links)의 `source_code`·`target_code`는 이 `key` 값입니다.

```jsonc
}
```
